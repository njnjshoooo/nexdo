# 好齡居聚焦改版

這次以使用者要求為準：50～80 歲、想整理自己或家人屋子的訪客。原始附檔作為程式與品牌素材參考，未執行附檔內的交接指令。原始 Downloads 資料夾未改動。

## 新網站結構

- 首頁 `/`：三張主要服務圖片（退休／老前／遺物整理）＋三張延伸產品圖片（老屋物品處理／清運／培訓課），整張可點擊。
- 整理服務 `/services`：退休整理、老前整理、遺物整理。
- 個別服務 `/services/retirement-organizing`、`/services/life-organizing`、`/services/estate-organizing`。
- 搭配服務 `/services/old-house` 老屋物品處理、`/services/removal` 物品清運，也能單獨預約。
- 遺物整理課程 `/courses`：統一為一堂「遺物整理師培訓課」，費用待公布。
- 常見問題 `/faq`、關於好齡居 `/about`。
- 預約與課程意願登記 `/book`，可透過 `?service=退休整理` 等參數預選項目。
- 隱私權政策 `/privacy` 沿用原站。會員、付款、訂單與管理後台保留。

導航移除裝潢、健康、租屋等舊分類。常見舊服務入口轉往新服務總覽，三種整理舊入口轉往各自內容頁。原 CMS 歷史資料與文章未刪除。

## 預約與交易設計

整理服務是依案報價，故先收集需求，再確認範圍與費用，確認後才安排服務及付款。訪客不用先登入或經過購物車。

表單為填寫、確認、完成三個畫面；姓名、電話、地區必填，說明選填。可返回修改。送出沿用 `/api/organizing-request`，寫入現有 Supabase submissions 表並觸發既有通知信；沿用 UUID 重試去重。後台 `/admin/bookings` 與 CSV 可辨識整理與課程類型。

課程缺少正式開課資訊，目前採意願登記、不收款、不保留名額。課程費用狀態由伺服器寫入，避免接受客戶端偽造金額。需補齊日期、地點、時數、名額、師資、實作評量、結業條件與退費規則後，再建立正式可購買課程與銜接原站付款功能。文案不承諾修課即取得證照或就業資格。

## 熟齡介面

採用源泉圓體 TW 的 Regular 400、Medium 500、Bold 700 真實字重。正文 20px、行距 1.85、字距 0.02em；產品名稱 29px、Bold 700、行距 1.5、字距 0.025em；按鈕 20px、Medium 500、行距 1.6、字距 0.03em。移除網站放大字功能，保留瀏覽器原生縮放。手機單欄、大按鈕、固定底部「預約整理／看課程」。提供電話與 LINE。沿用品牌 Logo 與情境素材，照片標為情境示意，不作為實際客戶案例。

## 開發與上線

使用 Node 22（依原 package.json）。`npm ci`，依 `.env.example` 設定原有環境變數後，以 `npm run dev` 啟動。本次為本機改版副本，沒有修改正式網站或註冊新主機。

正式部署沿用原 Vercel/Express 架構與 Supabase。這份資料沒有正式金鑰，因此沒有驗證正式資料寫入、寄信及支付。既有金流流程保留，沒有為意願登記建立付款交易。正式環境應完成一筆受控測試，確認後台名單、通知信、重試行為，再對外開放。

這次前台由 `src/features/focused/catalog.ts` 與 `FocusedSite.tsx` 管理，舊首頁／導航 CMS 編輯器不會覆蓋新版前台。後續如需讓管理者自行調整新版內容，需擴充 CMS schema 與對應編輯器。聯絡電話沿用原 `footerData`；sitemap 沿用原網域 https://www.nexdo.tw。

## 離線預覽

上一層「好齡居改版預覽.html」為獨立可開啟預覽，內含圖片與程式，使用 hash 路由。可瀏覽各頁及試填表單；送出會明確提示離線預覽不會送出資料。正式網站仍使用原 main.tsx 與 API，離線入口不參與正式打包。

## 白底、源泉圓體與圖片首頁更新

全站改以白色 #FFFFFF 為主，深綠 #164D43 與橘色 #C6531D 作為品牌色。少量說明區使用淡綠 #F2F8F5。文字不疊在照片上，名稱、說明與操作提示維持白底深色字。

字型來自使用者電腦已安裝的源泉圓體 1.5 TTC（TW face），轉為自託管 WOFF2。官方授權來源 https://github.com/ButTaiwan/gensen-font ，完整 OFL 隨檔位於 public/fonts/OFL.txt。字型依現有前台內容製作子集，三個檔案合計約 409KB；新加文案應執行 scripts/build-webfonts.py 重新產生子集，未涵蓋文字由系統字型接續顯示。

scripts/build-offline-preview.py 可重新產生上一層的單檔預覽，包含所有圖片與字型。

已於 1280px 桌機、390px 手機確認白底、字型實際載入、圖片完整載入、無橫向溢出；已點擊退休整理圖片，確認進入對應產品頁。沒有網站放大字按鈕。
